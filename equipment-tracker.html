Transaction Log

For logging individual card transactions as Penske runs them — pre-authorizations, true-ups, holds. One row per transaction. Built for fast entry while you're on the phone with them.

Quick weekly entry

Just like the sheet: unit #, type, card used, this week's due amount, and next week's rewrite amount. Type/location auto-fill from the unit if it's already on file — edit if it's wrong. Both post on the same Friday you select — the due amount settles the week that's ending, and the rewrite is the pre-auth for the week that starts that day.
